## 来源及辨识层级

JR 东日本 2611 四张线路时刻表（全线新津→会津若松→郡山为**上行**，逆为下行）：
- 平日上行 https://timetables.jreast.co.jp/2611/timetable-v/261u1.html
- 土休日上行 https://timetables.jreast.co.jp/2611/timetable-v/261u2.html
- 平日下行 https://timetables.jreast.co.jp/2611/timetable-v/261d1.html
- 土休日下行 https://timetables.jreast.co.jp/2611/timetable-v/261d2.html

官方的线路车辆介绍：[E721](https://www.jreast.co.jp/train/local/e721.html)、[GV-E400](https://www.jreast.co.jp/train/local/gv_e400.html)、[キハ110](https://www.jreast.co.jp/train/local/kiha110.html)，确定线路车型而非每天实车。2026-06 的[铁道时事说明](https://www.toretabi.jp/railway_info/entry-25366.html)记载郡山至会津若松的定期车全部为 E721。

会津若松—新津区间有 **GV-E400 与 キハ110** 两种独立的固定运用。按 **2025-09 的车号车型记录** <https://kitatetu-e233sai157.com/?p=61389> 逐个关联，2026-11-03 的[车次运用索引](https://w.atwiki.jp/train-boundfor/pages/196.html)及 2026-05/06 的[乘车记录](https://rail7.blogspot.com/2026/05/aizu-wakamatsu.html)对其多项进行了印证。这是**历史运用的参考匹配**，不证明 2026-11-05 当天的具体车辆或代走，亦非 JR 官方逐车次编组证实。

2026-11 SQL `public.manual_timetable_templates` 为 `BanetsuWest` 记录定期车 94 个唯一车号（E721 36、未分型 D 58），但 `train_timetable_vehicle_mappings` 对这些号均为空，非电化 D 统一标记为 `GV-E400系 / キハ110系` 混合候选。新增前端依照独立来源，**不更改 SQL，也不把实际车身份升级为 EXACT**。

## 规则与范围

- 全部来源约束 `BanetsuWest` + `odpt.Railway:JR-East.BanetsuWest` + `JR-East` + `2026-11` + 完整号 + 运行类别 + 上下行偶奇 + 平日/土休日及必要的 `operatingDates`。
- 图片仅使用仓库既有 `E721系_仙台地区`、`GV-E400系`、`キハ110系`、`C57形_180号機_SLばんえつ物語`、`DE10形_DLばんえつ物語`。图库原本已经为这些车设定 BanetsuWest 范围。
- 如列车来源明确的实时车型与历史参考冲突则拒绝图像。照片与公共时刻表不确认实际编组；返回结果为 `planned:true`。任何缺少真实车型图片或没有确认车号的临时列车仍保持中性灰点，**不虚构车辆图片、时刻或列车**。
- 不修改列车视图、弹窗、折叠、提示或位置算法；不改数据库；与其他线路图片隔离。
