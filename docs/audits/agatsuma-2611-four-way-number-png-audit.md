车型官方依据：
- JR 东日本 [211系](https://www.jreast.co.jp/train/local/211.html)：明确列出吾妻线属于运用线路；属于**线路车辆参考**，不是当天实车识别。

SQL 核对：`manual_timetable_templates` 的 `Agatsuma` 已有平日/假日上行、下行各 14 个普通车次（`211系（高崎地区）`；映射层级 `official_single_fleet_plan`，未证当天实车）及定期／周末特急（`E257系5500番台`；`official_service_vehicle_plan`）。前端缺少直接 `Agatsuma` 车号→PNG 和对应图库线路授权，因此图上仍是灰点。

## 运行时条件与安全边界

1. 采用现有`TrainNumberPngRanges.match` + `TrainVehicle.lookupTrainNumberRangePng`，只给**有实际计划时刻的列车位置**提供静态图库 PNG；绝不额外生成列车、站时刻或实时 GPS 数据。
2. `Agatsuma` 的 211 与 E257 库存已登记到 `VehicleGaragePngMap`，211 的规范车型目录也加入 `Agatsuma`。没有新增图库图片。
3. `vehicleIdentityStatus` 不自动升级为 `EXACT`，图片标记为 `planned:true`；说明是车型/线路参考，不声称已确认当天实车编组。
4. 原来的 `Takasaki` 规则、列车列表、灰点生成、提示文案、窗口交互和位置算法均不修改。
