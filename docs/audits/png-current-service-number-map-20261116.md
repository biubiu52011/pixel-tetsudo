## 2026-11-16 追加的官方现役车系证据

- 在原有 55 张基础上，追加 **31 张 JR 东日本现役车系 PNG** 的官方车系/运行线路证据；包括 209、211、E129、E131、E231、E257、E531、E653、E721、E751、EV-E301、EV-E801、HB-E210、HB-E220、キハ110、キハE130 等。
- 因这 31 张 PNG 原有列车番号规则，现役车系且有既存番号证据的 PNG 从 **52 增加到 83**；旧号码规则原封不动，不会把范围内不存在或未证实的列车自动认作当日实际运用。
- 多数证据确认的是**车系现役**与运行线区，非某一涂装／编成的逐日使用。**只有通过原有逐号/校历/来源守卫后，才可以从此索引寻找 PNG 候选。** 对特殊涂装以及跨型号的宽号段，仍需独立逐号证据。
- 本次**未新增任何号码规则**，未改动 JS 运行时、Supabase 数据或 Edge Function。未确认车号、编成或特殊涂装不得因车型同名而自动继承号段。

## 规则

1. **现役证据必须精确关联到 PNG 文件路径**，并引用运营方资料；不能把某一车型的在籍状态直接推广到不同涂装或限定编组。
2. **番号来源继续使用既有** `TrainNumberPngRanges`、SQL 和 `TrainVehicle`。新的现役筛选文件不能被前端当作通配号段列表。
3. `min/max` 只是数字上下界，不能自动填充两个端点之间不存在的号。
4. **计划车型／线路代表图**只能 `planned`；不允许升级为已观察的物理车组身份。
5. **475 张待确认**不等于 475 张退役。只有取得退役官方资料、且确认图片对应的限定编组/涂装后，才可以准确排除特定图片。
