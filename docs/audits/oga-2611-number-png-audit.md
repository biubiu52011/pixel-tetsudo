## 二、2611 官方列车番号

**上行（男鹿→追分，偶数，共 15）**

`1120M,1122M,1124M,1126M,1128M,1130M,1132M,1134M,1136M,1138M,1140M,1142M,1144M,1146M,1148M`

**下行（追分→男鹿，奇数，共 14）**

`1123M,1125M,1127M,1129M,1131M,1133M,1135M,1137M,1139M,1141M,1143M,1145M,1147M,1149M`

两种日历均有以上 **29 个普通 M 番号**，因此按列车番号与日历展开共 **58 个官方号码/日历条目**；不能将 58 条误当成单日开行数量。

官方 259u2/d2 中包含跨月临时车，但 2026-11 **均不运行**：
- `9129D / 9134D`：2026-12-19 「ストーブなまはげ」。
- `9135D / 9146D`：2027-02-13、14 「なまはげ柴灯まつり」。

这些 D 号不属于男鹿線 2026-11 常规车辆 PNG 范围。

## 三、SQL 旧模板与严格来源准入

Supabase 原始 `manual_timetable_templates` 有 **52 条历史模板**：

| 服务日历 | 上行来源 | 下行来源 | SQL 来源合计 | 官方番号合计 |
|---|---:|---:|---:|---:|
| 平日 | 12 | 11 | **23** | **29** |
| 土曜·休日 | 15 | 14 | **29** | **29** |
| **合计** | **27** | **25** | **52** | **58** |

缺少的平日 6 个 SQL 来源为：`1130M,1132M,1134M`（上行），`1131M,1133M,1135M`（下行）。它们**除了 11/5 以外在官方平日表中是正常班次**，但当前 SQL **没有逐站可查询模板**。不能用周末模板冒充平日运行或从其他时刻插值创造新的位置。

新增 migration `supabase/migrations/20261106053000_oga_2611_exact_e801_sql_number_calendar_roster.sql`，创建启用 RLS 的 `published_oga_2611_number_roster`：
- 58 条官方号码/日历数据（`calendar_scope='sql_rail_service'` **52 条**；`published_number_no_sql_source` **6 条**）。
- 每条有来源的 SQL 记录与 **source_template_id + 9 个真实来源站点 key** 一一关联；无源则 `source_template_id=NULL`、无来源站序，前端禁止估算。
- `published_train_number_evidence` 新增 **52** 条可关联 SQL 原始模板的证据；`published_train_png_number_ranges` 新增一条严格依赖精确 roster 的 `1120~1149 M` EV-E801 系 PNG 范围。范围只用于辅助，不单独授予 PNG 权限。
- 上行站序：**男鹿、羽立、脇本、船越、天王、二田、上二田、出戸浜、追分**；下行反向，两个方向均严格 **9 站**。原 SQL 只包含追分～男鹿这段，虽然官方同一车次表还列出接续秋田站，但**不可无来源外推至奥羽本线**。

## 四、特别运行日期

| 日期 | 官方公布的特殊情况 | SQL / 图面处理 |
|---|---|---|
| **2026-11-05（周四）** | 设备维护：`1130M,1132M,1134M` 及 `1131M,1133M,1135M` **6 个车次停运** | 严格过滤；不生成这些列车的计划位置或车型 PNG |
| **2026-11-20（周五）** | `1145M` **时刻变化**（官方表将秋田 19:55 改为 19:58、追分 20:13 改为 20:16，沿途部分站点也变化） | 历史 SQL 缺少这天的正式修正源，**仍认定车次存在，但暂不投影旧时刻位置**；不得将它显示成停运 |
| **2026-11-03、23** | 日本法定假日 | 正确使用 **SaturdayHoliday** 时刻表，而非一般工作日 SQL |
| 其他普通平日及土休日 | 29 个官方常规编号 | 有 SQL 的才在对应日历下显示，缺源的 6 个工作日号码不能虚构位置 |

### SQL 实际可绘制记录核查

| 日期 | 有 SQL 且未被日期例外禁止的计划记录 | 官方存在但 SQL 缺源 | 官方当日停运 / 时刻变更 |
|---|---:|---:|---|
| 11/03 | 29 | 0 | 无 |
| 11/05 | 23 | 6 | 上述 6 列车停运 |
| 11/06 | 23 | 6 | 无 |
| 11/07 | 29 | 0 | 无 |
| 11/20 | 22 | 6 | 1145M 时刻变更但无修正 SQL |
| 11/23 | 29 | 0 | 无 |

这里的数字是**有历史 SQL 来源且允许作为计划位置的记录数**，不是当日实际运行或实车追踪结果；已知所有旧来源的分秒钟点都标记为 `historical_not_2611_verified`，不能宣传为 2026-11 官方逐站秒表已对齐。

## 六、边界

**已确认：** JR 东日本官方 2611 公开的列车番号、服务日历、日期型停运/时刻变更说明；车辆族官方 EV-E801；以及 52 条已有 SQL 站序中的 9 站形式。
