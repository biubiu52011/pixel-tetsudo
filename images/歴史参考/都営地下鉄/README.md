# 都営地下鉄｜歴史参考画像

このディレクトリは**現行列車の番号→PNGマッピング対象外**の歴史参考アーカイブです。
``images/列车/`` とは分けて管理し、現行の車両ガレージと自動番号マッピングには登録しません。

## 都営地下鉄_12-000形_初期塗装_参考_車号要確認.png

- ユーザー提供の82×98 PNGを**元のバイト列のまま**保管（Git blob `621a746333947e29c7c6de1b2b07e65418b2bdc6`）。
- 白色塗装・前面形状は12-000形量産初期（1・2次車）に近い**イラスト**です。実車写真ではありません。
- イラスト前面の車号 **12-001 は不整合の可能性**があります。実在した12-001は1986年の試作車で、量産初期車とは異なる前面形状です。画像から正確な実車・編成を認定しません。
- 量産初期（白色塗装）の営業車は2016年6月30日までに運転を終えています。**2026年の営業列車・番号帯・編成実績に流用不可**。
- 参考：[日本地下鉄協会・東京都交通局の車両ガイド](https://www.jametro.or.jp/subway/japan/tokyo/guide.html) ／ [鉄道ファン・2016年の初期車営業終了](https://railf.jp/news/2016/07/01/171000.html) ／ [12-001試作車の相違点](https://mc127-100.hatenablog.com/entry/2022/01/04/192452)

既存の12-000形4次車・12-600形1次車画像はそれぞれ別画像として`images/列车/都営地下鉄/`に既に登録済みで、ユーザー提供の前2枚とGit blobが一致するため重複追加していません。
